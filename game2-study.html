Assembly essentials

Operands and widths

AT&T syntax uses source, destination. movq %rax,%rbx copies a register; movq (%rax),%rbx loads memory; movq %rbx,(%rax) stores to memory. leaq 8(%rax),%rbx computes an address without reading memory.

D(base,index,scale) computes D + base + index × scale; real x86-64 scales are 1, 2, 4, or 8. A memory operand then accesses that address. A leaq stops at the calculation. HW11 used 7 as a scale in some arithmetic exercises; that is not an encodable x86-64 scale.

Suffixes b, w, l, and q mean 1, 2, 4, and 8 bytes. Writing %eax clears the upper half of %rax; writing %ax or %al leaves the other bits unchanged. Sign extension replicates the sign bit; zero extension adds zeros.

Comparisons and control flow

subq %rsi,%rdi changes %rdi to %rdi - %rsi. cmpq %rsi,%rdi sets flags as if computing that subtraction but does not store it. testq %rax,%rax commonly checks for zero. The most recent instruction that changes the relevant flags controls the jump; lea does not change flags.

After that comparison, jl/jle/jg/jge are signed less/less-or-equal/greater/greater-or-equal; jb/jbe/ja/jae are unsigned below/below-or-equal/above/above-or-equal. je and jne test equality. Label both the taken and fall-through paths.

For loops, find initialization, entry test, body, update, and backward jump. A do-while executes its body before its first test. A jump table maps indices to code addresses; inspect the range check, repeated targets, and fall-through paths.

Structures and unions

Keep fields in declaration order, align each field according to the specified ABI, and round the final size to the largest member alignment. For struct T { short s; double d; char c; } under the usual x86-64 rules, offsets are 0, 8, and 16; the total is 24 bytes. Thus &a[i].c is base + 24*i + 16. Union members overlap at the same starting address; its size accommodates its largest member and alignment.

Calls and stack

For System V x86-64, the first six integer/pointer arguments use %rdi, %rsi, %rdx, %rcx, %r8, %r9; the usual return register is %rax. pushq decreases %rsp by 8, call pushes the next instruction's address, and ret pops it. Draw the stack and update %rsp after every instruction that changes it.

%rbx, %rbp, and %r12–%r15 are callee-saved, and the stack pointer must be restored. A callee that changes a callee-saved register must restore its caller's original value. Argument registers, %rax, %r10, and %r11 are caller-saved. Each recursive call has its own frame.

Overflow and defenses

A write outside an object can corrupt nearby data or control information. Count the terminating \0: a 24-byte array holds at most 23 input characters plus the terminator. The actual frame layout determines what gets overwritten.

Correct bounds checks and bounded input prevent the write. A canary can detect some overwrites before return; ASLR makes addresses less predictable; non-executable stack pages obstruct execution of injected stack bytes. These mitigations do not make an unbounded write safe.

Mixed practice

Work each problem before opening its answer. Assume 64-bit registers and the stated System V conventions.

1. Effective address and memory

Problem: %rax = 0x1000 and %rdx = 3. What address does 8(%rax,%rdx,4) calculate? What is the difference between using it with leaq and as a movq source?

Show answer

Answer: 0x1000 + 3*4 + 8 = 0x1014. lea returns that address; movq reads eight bytes beginning there.

2. Partial register writes

Problem: Starting with %rax = 0x1122334455667788, find the result of movl $1,%eax. Separately, find the result of movb $1,%al.

Show answer

Answer: The 32-bit write gives 0x0000000000000001; the byte write gives 0x1122334455667701.

3. Signed and unsigned branches

Problem: After cmpq %rsi,%rdi, when are jl target and jb target taken?

Show answer

Answer: jl tests signed %rdi < %rsi; jb tests unsigned %rdi < %rsi. The same bits can produce different answers.

4. Trace a loop

Problem: What does this return for %rdi = 3? Does the body run if it starts at zero?

movq $0, %rax
.L: addq %rdi, %rax
    subq $1, %rdi
    jne .L
    ret
Show answer

Answer: It adds 3, 2, and 1, returning 6. The body runs before the test, even for zero; then the machine value wraps and the loop does not immediately terminate.

5. Struct layout

Problem: Under the usual course x86-64 assumptions, find the offsets and size of struct S { char c; int x; short y; };.

Show answer

Answer: c is at 0, x at 4, y at 8, and total size is 12 bytes. The total includes trailing padding to a multiple of 4.

6. Trace a call

Problem: Before a call, %rsp = 0x1000; the next instruction is at 0x401005 and the callee begins at 0x402000. What changes immediately after the call?

Show answer

Answer: %rsp = 0x0ff8, the new stack top contains 0x401005, and %rip = 0x402000.

7. Buffer boundary

Problem: A 24-byte buffer begins at the current %rsp, with its saved return address immediately above it. How many input characters plus a null terminator first reach the return-address slot?

Show answer

Answer: 24 characters fill offsets 0–23; the terminator reaches offset 24. Other compiled layouts may include padding, saved registers, or a canary, so calculate from the layout given.
